ADD COMPLETE DUA & AZKAR BOOK to my Madrasa Management App "Darul Uloom Sirajul Islam Kalgaon" with THREE LANGUAGE SUPPORT (English, Hindi, Urdu).

## FEATURE OVERVIEW:
Create a beautiful Dua & Azkar Book containing:
- Daily Duas (Morning & Evening)
- Salah Duas (Prayer Duas)
- Quranic Duas (Duas from Quran)
- Special Occasion Duas

## LANGUAGE SUPPORT:
Every Dua must be displayed in THREE languages:
1. **English** - Translation
2. **Hindi** - हिंदी अनुवाद
3. **Urdu** - اردو ترجمہ

User can toggle between languages using existing language button or add separate language selector for Dua book.

javascript
function setDuaLanguage(lang) {
  const duas = document.querySelectorAll('.dua-translation');
  duas.forEach(dua => {
    if (lang === 'english') {
      dua.innerText = dua.dataset.english;
    } else if (lang === 'hindi') {
      dua.innerText = dua.dataset.hindi;
    } else if (lang === 'urdu') {
      dua.innerText = dua.dataset.urdu;
    }
  });
}
